# Web Technology Notes (CS35302)

A free, easy-to-read notes website for the **Web Technology** course of B.Tech CSE, 5th semester, at Quantum School of Technology. The notes follow the official syllabus unit by unit, so you can read them like a book.

**Live site:** https://YOUR-USERNAME.github.io/webtech-notes/

## Features

- Notes organised by unit and topic, following the syllabus
- Search box that finds any topic or keyword
- Tick a topic when you finish it; a progress bar shows how much you have covered
- Light and dark mode
- Works on phones, tablets and computers
- Plain HTML, CSS and JavaScript, with no framework and nothing to install

## Syllabus covered

| Unit | Title | Topics include |

| 1 | Internet Foundations | History of the Internet, WWW and HTML, HTTP, SMTP, POP3, MIME, IMAP, DNS, web browsers, web servers |
| 2 | Markup, Styling and XML | Lists, tables, images, forms, frames, CSS, JavaScript and DHTML, DTD, XML Schema, object models, DOM and SAX |
| 3 | Web Services and Ajax | UDDI, SOAP, WSDL, web service architecture, developing and deploying services, Ajax, CORBA |
| 4 | Web 2.0, Web 3.0 and Modern Trends | Blogs, wikis, RSS, Ruby on Rails, Open APIs, Semantic Web, RDF, mashups, search engines, recommender systems, blockchain, edge computing, dark mode |
| 5 | Web 4.0 and the Future | AI-powered web, decentralised web, IoT, AR and VR, adaptive interfaces, web automation, 5G |

## Project structure

```
webtech-notes/
├── index.html   page structure
├── style.css    design, colours, light and dark themes
└── script.js    all notes data, search, progress tracking
```

## Run it on your computer

1. Download or clone this repository.
2. Open `index.html` in any browser.

No server or installation is needed.

## Add or edit notes

All notes are stored in the `U` array at the top of `script.js`. Each topic is written as:

```js
["Topic title", "notes written in HTML"]
```

Change the text, save the file, and refresh the page.
